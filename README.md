# cronos-metrics-site

Static pages for the **Cronos Metrics** developer apps (TikTok, Instagram): privacy policy, terms of service, and the OAuth redirect page. Hosted on GitHub Pages.

Before publishing, replace the placeholders in `privacy.html` and `terms.html`: `[DATE]`, `[LEGAL ENTITY NAME]`, `[CONTACT EMAIL]`.

Pages once published (replace `<user>` and `<repo>`):

- https://<user>.github.io/<repo>/privacy.html
- https://<user>.github.io/<repo>/terms.html
- https://<user>.github.io/<repo>/callback.html  (redirect URI)

TikTok's URL-property verification file goes in this folder's root, next to `index.html`.
